## 3. Running the Agent (The Simple Way)

Instead of using the Livekit Playground (which was blocked/buffering), we use **Console Mode**. This runs everything locally on your machine.

**Command:**
```powershell
uv run examples/voice_agents/test_interrupt_agent.py console
```

## 4. How to Verify (for Video)

Once the agent starts and you see logs:

1.  **Wait** for the agent to say "Hello..." (or see the log "Agent - Successfully sent hello message").
2.  **Test 1: Normal Conversation**
    - Say: *"Tell me a story about space."*
    - Agent: Starts speaking...
3.  **Test 2: Ignore List (While it speaks)**
    - Say: *"Yeah"*, *"Uh-huh"*, *"Right"*.
    - **Result:** Agent should **KEEP TALKING**. (Success)
4.  **Test 3: Interruption (While it speaks)**
    - Say: *"Stop!"* or *"Wait!"*.
    - **Result:** Agent should **STOP IMMEDIATELY**. (Success)
